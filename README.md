# Residential Building Construction: Project Planning and Scheduling

**Project Planning, Scheduling, Cost Estimation, Resource Allocation, and Critical Path Analysis Using Microsoft Project**

## Project Overview

This repository presents an individual academic project focused on planning and scheduling the construction of a **single-storey residential building** using Microsoft Project.

The assignment provided overall **time and budget constraints**, while the detailed project plan—including activity definition, duration estimation, task dependencies, resource allocation, and cost distribution—was developed to satisfy these constraints.

The project demonstrates the application of industrial engineering and project management techniques to a realistic construction planning scenario.

## Project Objectives

The main objectives were to:

- Develop a structured Work Breakdown Structure (WBS).
- Define construction activities and their logical dependencies.
- Estimate activity durations and prepare a feasible project schedule.
- Allocate labor, equipment, and material resources.
- Estimate project costs while considering the assigned budget constraint.
- Identify the critical path and schedule-sensitive activities.
- Analyze planned cash flow, resource utilization, and project progress.
- Present the results through Microsoft Project and a comprehensive project report.

## Project Planning Methodology

### 1. Work Breakdown Structure (WBS)

The construction project was divided into four main phases:

| Phase | Planned Cost (Million Toman) | Budget Share |
|---|---:|---:|
| Project Management & Planning | 92.1 | 9.2% |
| Site Preparation & Mobilization | 275.2 | 27.6% |
| Structure & Rough Construction | 337.1 | 33.8% |
| MEP & Finishing Works | 293.7 | 29.4% |

The WBS covers project initiation, site preparation, foundation construction, structural works, mechanical and electrical installations, finishing, and final handover.

### 2. Activity Scheduling and Gantt Chart

The project schedule was developed by:

- Defining activities and estimating their durations.
- Establishing predecessor-successor relationships.
- Accounting for necessary waiting periods, including concrete curing.
- Allowing appropriate overlap between project phases.
- Applying a project calendar with defined working and non-working days.
- Monitoring planned activities through Gantt charts.

The resulting baseline schedules construction activities from **February 1 to July 22, 2026**.

### 3. Critical Path Analysis

Critical Path Method (CPM) principles were used to identify activities with zero total float.

The project plan contains **72 critical activities**, grouped into **16 critical work packages**.

The critical sequence extends from initial project definition through site preparation, foundation and structural construction, finishing, and final handover.

Identifying these activities helps highlight where delays could affect the planned project completion date.

### 4. Cost Planning and Budget Allocation

Project costs were estimated through resource assignments and their corresponding rates.

The analysis includes:

- Cost allocation across construction phases.
- Cost estimation for individual work packages.
- Labor, machinery, and material cost breakdowns.
- Cumulative planned cost analysis using an S-curve.
- Monthly cash-flow requirements.

The total modeled project cost is **997,984,000 Iranian Toman**.

The largest budget allocation is associated with **Structure & Rough Construction**, representing approximately **33.8%** of total planned cost.

### 5. Resource Allocation and Workload Analysis

The project incorporates **12 resources**, including:

- Laborers
- Engineers
- Foremen
- Project manager
- Electricians
- Plumbers
- Machinery
- Construction materials

Resource planning considered hourly or unit rates, availability limits, required quantities, and task assignments.

The report also examines weekly workload distribution and daily labor requirements.

The maximum planned daily laborer headcount is **22**, remaining within the modeled availability limit of **25 laborers**.

### 6. Project Progress and Control

A project status date of **March 1, 2026** was used to demonstrate progress monitoring.

The modeled progress snapshot includes:

- Overall project completion
- Work completion
- Phase-level progress
- Actual-cost entries within the academic scenario
- Remaining budget and cost variance

This section demonstrates how Microsoft Project can support schedule and cost monitoring.

## Key Findings

The project planning analysis produced several notable results:

- **72 activities** were identified as critical to the project schedule.
- Structural and rough construction accounted for the largest share of planned costs.
- Human labor represented approximately **90.6%** of the modeled project budget.
- The peak planned monthly expenditure occurred in **April 2026**.
- Resource workload analysis indicated a peak of **22 laborers**, below the specified availability limit.
- The schedule incorporated overlapping phases and mandatory waiting periods to reflect construction dependencies.

These findings are based on the academic project model rather than the execution of an actual construction project.

## Assumptions and Limitations

This project was developed as an **academic planning exercise**, not as documentation of a completed real-world construction project.

The overall time and budget constraints were specified in the assignment. Activity durations, dependencies, resource assignments, and cost allocations were developed as part of the planning exercise.

The progress snapshot is part of the modeled project scenario and does not represent independently verified on-site construction progress.

Cash-flow and workload visualizations in the report use planning approximations derived from resource assignments.

All monetary values are expressed in **Iranian Toman**.
